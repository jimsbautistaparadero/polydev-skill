# Defense Readiness Checklist

## Research logic

- [ ] I can explain the practical problem and the evidence proving it.
- [ ] I can state the research gap without exaggerating novelty.
- [ ] Every objective maps to a research question and result.
- [ ] I can justify the framework and methodology.

## Evidence and method

- [ ] I can explain how sources were searched and verified.
- [ ] I can justify the population, sample, and sampling procedure.
- [ ] I can explain instrument development, validation, and pilot testing.
- [ ] I can explain data collection, cleaning, and analysis decisions.
- [ ] I can identify major sources of bias and limitations.

## System/intervention (if applicable)

- [ ] I can demonstrate the system in the intended environment.
- [ ] I can trace core features to stakeholder needs and requirements.
- [ ] I can show test cases, actual results, and known defects.
- [ ] I can explain privacy, security, accessibility, and failure handling.
- [ ] I do not confuse a successful demo with proof of real-world impact.

## Results and contribution

- [ ] I can state the most important actual findings with evidence.
- [ ] I can distinguish observed results from interpretation.
- [ ] I can explain what the findings do not establish.
- [ ] My conclusions answer the research questions.
- [ ] My recommendations follow from the findings.

## Submission control

- [ ] Adviser-approved final version identified.
- [ ] References and in-text citations audited.
- [ ] Tables/figures/appendices checked.
- [ ] Presentation aligned with the final manuscript.
- [ ] Demo environment and backup recorded.
- [ ] Confidential and personal data removed from presentation materials.
